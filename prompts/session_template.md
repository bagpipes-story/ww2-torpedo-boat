# 2回目以降のセッション用テンプレ（iPhoneから貼る短い版）

`{{ }}` を埋めて貼る。長文は要らない。CLAUDE.md が手順を持っている。

```
CLAUDE.md と CHANGELOG.md の最新エントリ、docs/03 の {{対象バージョン}} を読んで。
今回は {{対象バージョン}}「{{段階名}}」。前回の既知の制約: {{1行}}
CLAUDE.md §6 の手順で進めて、終わったら Pages URL・ビルド番号・実機テスト項目3つ以内・既知の制約を報告して。
```

## よく使う一言

| 場面 | 送る文 |
| --- | --- |
| 確認が済んで取り込む | `マージして v{{x.y.z}} にタグを打って、CHANGELOG に実機テスト結果を書いて: {{結果1行}}` |
| CIが落ちた | `このPRを監視してCI失敗を直して` |
| 続きをやってほしい | `続けて。終わったら Pages URL と実機テスト項目を報告して` |
| 何を見ているか分からない | `いま公開されているビルド番号と、このPRの最新コミットを教えて` |
| 方針を変えたい | `docs/02 の §{{番号}} を {{変更}} に書き換えてから実装して` |
| セッションが切れた | セッションを開き直して `さっきの続き。状態を3行で要約してから再開して` |
