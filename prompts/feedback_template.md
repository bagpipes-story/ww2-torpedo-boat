# 実機で遊んだ感想を返す型（iPhoneから）

同じセッションに貼る。短くてよい。スクリーンショットを添付できる場合は添える。

```
実機テスト: iPhone {{機種}} / Safari / ビルド {{画面隅の番号}}
FPS: {{数値 or 体感}}
操作: {{OK / 親指が届かない / 曲がりすぎ など}}
命中: {{何本撃って何本当たった}}
直してほしい: {{1〜3個、番号付き}}
次にやる: {{v0.x.y に進む / このまま調整}}
```

## 例

```
実機テスト: iPhone 15 / Safari / ビルド claude/v0-1-3@a1b2c3d
FPS: 60で安定
操作: スティックの出現位置が左すぎて親指が届かない
命中: 4本撃って1本。雷跡が見えるのは良い
直してほしい: 1) スティックをタッチ位置に出す 2) 発射ボタンをもう少し大きく
次にやる: 直したら v0.1.3 をマージ
```
