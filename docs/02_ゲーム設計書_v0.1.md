# ゲーム設計書 v0.1（仮称: Night Hunters）

- 版: v0.1.0（2026-10-02）
- 位置づけ: 実装の正。史実の根拠は `01_史実リサーチ＆設計資料.md`、数値は `data/*.json`、順番は `03_開発ロードマップ.md`。
- 「v0.x」と書いた項目はそのバージョンで実装する。v0.1 で作るのは §1〜§5 と §6.1〜§6.3 の最小版だけ。

## 1. コンセプト

**「当たらない魚雷で、夜の海を生き延びる」**
夜間に敵艦へ忍び寄り、4本の魚雷をいつ・どこで撃つか決め、砲火をかわして帰投する2Dトップダウンのアクション。
命中は高報酬だが、スコアの基本は「生還」と「任務達成」。史実（命中率数%、損失の65%は敵以外）を下敷きに、命中率だけは爽快感側に寄せる。

## 2. プラットフォームと画面

| 項目 | 決定 |
| --- | --- |
| 対象 | iPhone（Safari PWA → Capacitor）。PCブラウザはデバッグ用 |
| 向き | 横持ち（landscape）。両手の親指で操作する |
| 論理解像度 | 1280×720。`Phaser.Scale.FIT` + `autoCenter`。余白は黒 |
| 描画解像度 | `min(devicePixelRatio, 2)` |
| セーフエリア | HUDは `env(safe-area-inset-*)` 分を内側に寄せる（ノッチ・ホームバー） |
| 視点 | トップダウン2D。カメラはプレイヤー艇を追従、既定ズーム 0.75（§6.10） |
| フレームレート | 60fps目標、50fps以上をDone条件にする |

## 3. コアループ

```
夜の接近 → 発射判断（4本の配分） → 命中？ → 離脱（煙幕・急転舵） → 帰投・生還
                                      ↓外れ
                              再攻撃か離脱か → 再接近（残弾と燃料がある間）
```

1ミッション＝1出撃。目安は3〜6分（v0.1 は30〜60秒）。

## 5. 操作（タッチ）

| 入力 | 動作 | 補足 |
| --- | --- | --- |
| 左半分のタッチ | フローティング・バーチャルスティック。X＝舵（-1〜+1）、Y＝スロットル（上で全速、中立で巡航、下で静音低速→停止） | スティックの出現位置はタッチ開始点 |

| ピンチ | ズーム 0.5〜1.0 | v0.3 |
| PCデバッグ | 矢印/WASD＝舵とスロットル、Space＝魚雷、Shift＝煙幕、Z＝ズーム | v0.1 |

## 6. ゲームシステム

### 6.1 艇の運動モデル（v0.1）

- 単位は実寸（m、m/s、度/秒）。`src/core/units.ts` で kt→m/s 変換（1kt＝0.5144m/s）。
- 速度は目標速度に向けて加速度で近づく（`accel_mps2`、減速は `decel_mps2`）。
- 旋回は舵入力×`turn_rate_deg_s`。速度ベクトルは常に船首方向（横滑りなし。v0.3で慣性を足すか判断）。
- 速力段（データ: `speed_silent_kt` / `speed_cruise_kt` / `speed_max_kt`）。静音低速では敵からの発見距離が縮む（§6.5）。
- 画面外に出ないよう、ミッションごとに海域境界（`bounds_m`）を持つ。境界外は「帰投ポイントへ戻る」導線にする。

### 6.2 魚雷（v0.1）

- 発射位置は艇の両舷（Mk 8は発射管、Mk 13はラック転落）。発射方向＝船首方向＋扇状オフセット。
- 魚雷は直進。速度と最大射程は `data/torpedoes.json`。射程到達で消滅。
- 発射から `arming_distance_m`（既定100m）までは命中しない。
- 雷跡（航跡）を描く。発射位置から現在位置まで、一定間隔で薄い点をプールから出す（毎フレーム生成しない）。
- 命中判定は幾何式: 艦の船体を「船体に沿った円の列」（長さに応じて3〜5個）で近似し、魚雷（点）との距離二乗で判定する。Arcadeの矩形は回転できないため使わない。
- 信頼性ロール（発射時に1回）: `dud`（命中しても爆発しない）と `erratic`（進路に±`jitter_deg` の一定偏差＋小さな蛇行）。確率は `data/torpedoes.json` の各魚雷の `reliability`（史実モードは `hit_rate_model.json` の `historical_mode.reliability` で上書き。`reliability_by_era` は参考値）。

### 6.3 命中率モデル（v0.1〜v0.5で調整）

命中はダイスではなく幾何で決まる。`data/hit_rate_model.json` の距離別目標値は **測定して合わせるKPI** であり、敵の回避パラメータ（発見距離・反応遅れ・転舵率）で結果がその帯に収まるよう調整する。

| 発射距離 | 目標命中率（正しい見越し角の1本） |
| --- | --- |
| ≤400yd（366m） | 60〜70% |
| 800yd（732m） | 45〜55% |
| 1,200yd（1,097m） | 30〜35% |
| 2,000yd（1,829m） | 10〜15% |
| ≥3,000yd（2,743m） | ≤5% |

- Missionシーンで発射ごとに `{range_m, hit:boolean}` を記録し、Resultで帯別の命中率を表示する（KPI計測）。
- 見越し角ガイド（`aim_assist`）: v0.1はデバッグ切替で常時表示可。製品では「レーダー装備」「経験」でアンロック（v0.5）。
- 史実モード: 敵の回避を強め、信頼性不良を10%にする（v0.5）。

### 6.4 敵（v0.1は駆逐艦1隻のみ）

| 敵 | 挙動 | バージョン |
| --- | --- | --- |
| 駆逐艦 | v0.1: 一定針路・一定速力（20〜30kt）。v0.2: 雷跡を `wake_detect_m` 以内で発見すると `reaction_delay_s` 後に雷跡と平行になるよう転舵（「櫛で梳く」回避）。探照灯・星弾でプレイヤーを照らし、主砲と機銃で射撃。接近されると衝突を狙う | v0.1 / v0.2 |
| 輸送船 | 低速（8〜12kt）、護衛付き。魚雷で沈む | v0.4 |
| 大発（バージ） | 岸沿いを低速で移動、機銃で反撃。魚雷は深度不足で下を抜ける（当たらない）。砲で撃破 | v0.4 |
| 水上機 | 夜間に照明弾を落とし、小型爆弾を投下。プレイヤーの航跡（高速ほど発見されやすい）で寄ってくる | v0.3 |
| Sボート／隼艇 | 魚雷艇同士の砲撃戦（日本ハードモードの護衛相手） | v0.6 |

数値は `data/enemies.json`。

### 6.5 視界と発見（v0.2）

- プレイヤーから敵が見える距離 `vis_player_m`（月明で変動）。レーダー装備なら `radar_m` 以内の敵を円で表示。
- 敵がプレイヤーを発見する距離は「基準距離 × 速力係数 × 月明係数 × 煙幕係数」。全速は航跡（夜光虫）で遠くから見つかり、静音低速なら近づける。
- 発見されると探照灯（扇形）と星弾（周囲を一時的に明るくする）が来て、砲撃が始まる。

### 6.6 被害（v0.2）

- 艇HP。砲弾は貫通して炸裂しないことが多い（小ダメージ）。直撃で `engine_damage`（最大速力低下）、`fire`（継続ダメージ。煙幕ボタン長押しで消火、簡易）。
- 燃料タンク直撃＝大爆発（即死ではなく大ダメージ＋火災）。
- 駆逐艦との衝突＝撃沈（PT-109）。

### 6.7 燃料（v0.3）

- `fuel_hours_cruise` / `fuel_hours_full` から消費率を出す。全速は巡航の約2.5倍消費。
- ミッションは帰投ポイントに戻って完了。燃料切れは漂流→失敗（生還率に影響）。

### 6.8 リスクイベント（v0.3）

`data/risk_events.json` の重み（史実の損失比率）で、ミッション中または出撃前に発生する。

| イベント | 発生条件 | 回避手段 |
| --- | --- | --- |
| 座礁 | 浅瀬（マップに暗い帯）に高速で入る | 速度を落とす、見張りズーム |
| 友軍誤射 | 味方機・味方艦が近くにいるときに識別信号を出さない | 「識別」ボタンを押す（v0.3） |
| 港内空襲 | 出撃前フェーズ（Briefing）で発生。艇が減る／損傷して出撃 | 分散退避のミニ選択（v0.4） |
| 暴風 | ミッション条件。旋回率低下、視界悪化 | 低速 |
| 機雷 | 機雷原の帯 | 航路選択 |

### 6.9 スコア（v0.1最小、v0.3で完成）

| 項目 | 配点 | 備考 |
| --- | --- | --- |
| 生還 | 大 | 帰投ポイント到達 |
| 任務達成 | 大 | 迎撃／護衛／輸送／救助など任務ごと |
| 命中 | 中 | 1本ごと。距離が遠いほどボーナス |
| 燃料残 | 小 | 全速の多用を抑える |
| 乗員生存 | 小 | 被害で減る |

日本ハードモードは「届けた物資量」「護衛対象の生存」を任務達成に置き換える。

### 6.10 時間圧縮とスケール

- 世界座標: 1ユニット＝1m。カメラ既定ズーム 0.75（画面幅で約1,700m）。
- 時間圧縮: 移動・魚雷・敵の回避はすべて `time_scale`（既定5）倍で積分する。史実の「1,500mで1〜2分」が「15〜20秒」になる。
- 見た目: 艇・艦のスプライトは `sprite_scale`（既定2）倍で描く。当たり判定は実寸のまま。

## 7. アート方針（v0.6まで）

- 夜の海: 背景色 `#0b1020`、波はパララックスの薄いノイズ1枚。
- 艇・艦: 明るい灰色の船形ポリゴン。魚雷は白い線分。雷跡は薄い点。探照灯は半透明の扇形。
- 色の意味を固定: 自艇＝白、敵＝薄い赤、味方＝薄い青、魚雷＝黄。
- 画像・音の制作にセッションを使わない。
