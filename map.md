## (a) Air-raid core, frozen files, and how to reuse without edits

Frozen (tests/frozen-files.test.ts, sha256, 20 files): `core/air-strike.ts`, `air-strike-state.ts`, `air-strike-pose.ts`, `air-strike-data.ts`, `air-strike-sim.ts`, `systems/air-strike-flight.ts`, `core/seaplane.ts`, `seaplane-ordnance.ts`, `gun-battery.ts`, `pt-boats.ts`, `pt-gun.ts`, `gunboat.ts`, `torpedo.ts`, `torpedo-targets.ts`, `torpedo-solver.ts`, `systems/torpedo-pool.ts`, `pt-state.ts`, `pt-contact.ts`, `pt-chase.ts`, `pt-damage.ts`.

Core facts (all frozen):
- `AIR_STRIKE_MAX_PLANES = 4` (air-strike-state.ts L10); `airStrikeParamsFromData` throws if `count` ∉ 1..4 (air-strike-data.ts L155). **One AirStrikeState = ≤4 planes.** "Bigger waves" ⇒ several instances.
- Geometry is **relative to `check.player`** (whatever BoatState you pass): planes spawn at `fromBearing + wave×rotate + offset[i]`, `spawnM` from that boat (air-strike.ts L20–34), orbit it, run in, aim with `predictBoat` (L76–80). Only targets are `c.player` and one `c.escort` (L113+ step; hit test L190–201). Bombs aimed at boat X never test other boats.
- Per flight only one bomb is ever in the air (validator: `run_gap_s > fall`; air-strike-data.ts L183) ⇒ ≤1 impact per step per flight.
- `cancel` (sinking ‖ atHome ‖ grounded) is one-shot: all planes leave and no more waves (air-strike.ts L118–120, L55–68). Restart is only via `core/air-sortie.ts` `restartAirSortie` (NOT frozen, L25–44: resets started/cancelled, re-spawns at a bearing/r around the *new* center).
- RNG: the flight draws 2 per release from the `SeededRng` passed in (L86–87); the world's `hitBoat` draws fire/engine from the same stream (world-hazards.ts L54).
- `AirStrikeFlight` (systems/air-strike-flight.ts, frozen) is a plain class: `new AirStrikeFlight(scene, p, rng, splash, onPlayerHit, onEscortHit)` (L59–82); `start(player)` L90; `step(feelDt, view)` L96–118 reads a *structural* view `{boat:{state,sinking}, atHome, grounded, escort}` (L38–43); `updateVisuals(centerState, escortState|null)` L121; each impact calls exactly one of `onPlayerHit(x,y)` / `onEscortHit` / `splash(x,y,true)` with the aim point. ~9 Images per instance (4 planes + 2×poolSize + 1 line).

**Reuse without editing a frozen byte (precedents exist):**
1. *Params with different wave timing:* call `airStrikeParamsFromData(aircraft, {id, params}, block, …)` with a **jp_03-only event record**; the id is not checked inside (air-strike-data.ts L138–153). Exact precedent: `config/patrol-air-mission-data.ts` L67 builds jp_02's sortie from `risk_events.patrol_air.params.sortie`. Do **not** change `risk_events.dawn_air_strike.params` (shared by us_01/us_03/jp_01/jp_02/jp_04/jp_06 → breaks md5s).
2. *Many targets:* N `AirStrikeFlight` instances, each fed a **fake view whose `boat` is the target squadron boat** (escort null). `onPlayerHit` of a non-player flight → damage that squadron boat (HP only, no rng, like escort/convoy); for the flight centered on the real player use the world `hit(spec, rng, x, y, 'air_strike')` as today.
3. *Collateral (bomb aimed at boat A lands on B / on the player):* wrapper-side check inside the `splash`/`onPlayerHit` callbacks with `pointNearBoat(x, y, boat, halfLen, radius)` (core/gunnery.ts) over all boats. Decide whether collateral exists (readability vs. "clustered boats die together" — the latter *is* the dispersal lesson).
4. *Retarget:* only between waves (all planes DONE, no bomb in air → `restartAirSortie` on a new target from the carrier bearing at `spawnM`) to avoid plane teleports (positions are relative to the center). Hidden/at-cover target mid-wave → set the fake view's `atHome = true` → that flight cancels and leaves (reads as "lost sight").
5. *AA (25mm):* `systems/aa-slots.ts` (not frozen) feeds `core/aa-fire.ts` `addStrikePlanes(t, s, p, boat=center, src, pose)` (L90–98, pass the flight's center). `AA_MAX_TARGETS = 8` (aa-fire.ts L17) < 16 planes — raise or add only nearest flights (other missions never exceed 4+2+1, so raising is neutral; verify aa-sim md5 / `tests/aa-*`). Downing: `core/air-down.ts` `downStrikePlane` (L13).
6. *A new Phaser-free raid sim:* frozen `core/air-strike-sim.ts` is single-boat; write a new core sim that calls `stepAirStrike` directly (pattern: `core/patrol-air-sim.ts` L1–10 imports `stepAirStrike`/`restartAirSortie`).
