## 確かめて問題なしとした点（反映なし）

- カリング: Phaser 3 の Image は境界でカリングしない（`camera.disableCull` 既定・描く判定は visible・α・renderFlags だけ）。テクスチャの寸法を保てば描かれ方の条件は変わらない。
- 字の位置: テクスチャの寸法を読むのは `entities/ally-ship.ts:55`・`entities/ally-destroyer.ts:53` だけ（spec §2.2 のとおり）。曳光弾の幅・高さは凍結の air-strike-flight と pt-squadron が読む（spec のとおり変えない）。
- 乱数: 今の絵の側でゲームの乱数を引く所は無い（storm-front の seed+3 は帯の状態＝論理）。カメラの揺れは Phaser の `Math.random`（今のまま）。
- `generateTexture` は既存の鍵の canvas に消さずに重ね描きし、大きさは変えない（`Graphics.js` の generateTexture）。描き直しの前の `clearRect` と同じ幅・高さの指定が要る（spec のとおり）。
- WebGL の TileSprite は `tilePosition` を書いても描き直さない（`updateCanvas` が gl で早く返る）。Canvas レンダラーは毎回描き直す（spec のとおり出さない）。
