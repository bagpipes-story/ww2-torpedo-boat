  - 合図と爆発の飛び出しの門（S2・spec §8.3）は ✗ のまま: 「頭 0.3 秒 − 直前 1 秒」の中央値の下がり ≤ 0.5 dB（警報 ≤ 0.2 dB）は §3.4 の音量（静か −33・緊張 −30・戦闘 −27 dBFS）では通らない（IP1 の後で警報 1.88・探照灯 1.89・魚雷の発射 1.96・被弾 1.12・爆発 0.95 dB。曲が合図の前の 1 秒にも鳴る分だけ必ず下がる＝下げは合図の頭からしか効かない）。通るのは 3 層とも約 −10 dB（本体ではほぼ聞こえない＝U-M1 の「任務中も静かに鳴る曲」にならない）の時だけ。合図の頭は同じ頭の曲（下げの後）より中央値で 9〜28 dB 上。前の 1 秒に爆発の無い爆発の飛び出しの最小は 4.5 dB（門 6.5 dB。曲なしでも 5.7 dB の窓がある）。S4 でも音量と門の決め直しはしなかった（耳で判断＝実機の項目 ①③。下げたいと言われたら 3 層の音量 `MUSIC_GAIN` か出口の目標を下げる）。
  - 段: 移りは hold（戦闘 6 秒・緊張 8 秒）だけで、probe の台本では 1 分の移り ≤ 5。人の遊び方（煙幕で見え隠れ・探照灯の往復）で 1 分に 6 回を超えることはありうる（移りの制限は入れていない）。jp_03 の昼の空襲も夜の任務と同じ家族。沈み始めの 2.5 秒の消えは、その前に Result へ移れば 0.5 秒（任務の終わり）で消える。
  - 作る時間: タイトルの曲ができるまで、効果音の列が終わってから約 225 フレーム（表 4・D の作曲 1・D を描く 221 回の stepBuild＝60 fps で約 3.8 秒。A を既定にしていた S1〜IP1 より約 0.7 秒遅い）、任務の 3 層まで約 395 フレーム（約 6.6 秒。その前に任務へ入ると 3 層を先に作り、タイトルの曲は後で頭から＝同じ標本）。1 フレームの予算は決まった量（150,000 単位）だが、作り始めのフレーム（作曲）は Chromium で 6.9〜9.7 ms（JIT の初回。Title の出始めに 1 回）・書き方の初回は 1 回 5〜11 ms が数回。iPhone の JavaScriptCore では 1 フレームの作る時間を測っていない（ヘッドレスの Chromium と node だけ）。低電力モード（30 fps）では作り終えるのに 2 倍のフレーム。最初のタッチ（touchend）まで曲は鳴らない。
  - 記憶: 常駐はタイトルの曲 D＋3 層の 1,730,400 標本（6.9 MB。上限 180 万）と波形表・雑音の表 約 0.3 MB（表は残す）。作業用の配列 2.7 MB は列が空になれば捨てる。
  - 再生: stop は 1 音源 1 回なので、急いで止めた組の節は予約の stop まで空かない（3 組分の 9 本）。3 層の組が 3 つ重なる（メニュー ⇄ 任務をすばやく行き来する）と、新しい組は止めかけの組が鳴り終わるまで（最大 1.2 秒）始めない（鳴っている音源 ≤ 6）。止まっていた context が動き出してから最初のフレームまで（約 17 ms）は一時停止の束・命中スローの立ち上がりと立ち下がりが前の形のまま（止まっている context に書かない作法）。下げは曲が鳴っていない時も下げる音量のノードに書く（聞こえない・確保なし）。遅れて始める時と最初の音の 2 秒（firstInS）とふだんのメニューの 2 秒（menuInS）は今は同じ値。
  - 命中スロー: iPhone（WebKit）の BiquadFilter・playbackRate の予約は測っていない（ヘッドレスの Chromium だけ。実機の項目 ②）。ループの rate の予約はループの再生の時定数 0.08 秒・10 Hz の決め（ループは濾波器と曲より速く戻る）。案 A の 2 kHz より上の下がりは「曲: オフ」の出口で約 11 dB（曲ありは約 16 dB）。濾波器の Q は既定（1,100 Hz の間は 0.5〜1.1 kHz が約 +1 dB）・ふだんの 20 kHz の差は 48 kHz の context で最大 +0.29 dB。オフラインの mix はスローの窓を写していない（ベッドを下げるだけなので甘くならない側）。
  - 曲の中身: 継ぎ目は「頭と末尾の差 < 0.02」ではなく、輪の尾が頭へ続く・差が中の差の 99% の内・継ぎ目をまたぐ 50 ms の RMS が前後の ±2 dB の内で固定（拍の頭に音のある輪では普通の隣どうしの差より小さくできない）。部屋の響きは作る時に 1 回だけ足すモノの響き（左右の広がりなし）。打楽器の層（L1・L2）の頂の丸めで直流が最大 3e-4 残る（−70 dBFS）。旋律の点は耳の代わりの目安（上位の差は小さい＝0.929・0.927・0.926。ほかの候補を聞きたいと言われたら上位の種で作れる。作曲器・点を直すと種の答えも標本も変わる）・種は 400 個の区間（決まりを全部通るのは 52 個）。12 小節目の終わりの上がり（B♭4 → G5 の 6 度の跳躍で 13 小節目へ）は跳躍の戻りの決まりの結果の形。対旋律は旋律より約 7 dB 小さい（本体では聞こえにくい）。発音の密度・2〜5 kHz の帯の数は目安（`scripts/sfx-files` の onsetRate）。
